# Guide d'utilisation simplifié — Korg SV-1

Guide en français, pensé pour les non-techniciens et lisible sur téléphone.

## Mettre en ligne avec GitHub Pages

1. Sur github.com, créez un nouveau dépôt (par exemple `guide-korg-sv1`), public.
2. Cliquez sur **Add file → Upload files** et déposez `index.html` (et ce `README.md`). Validez avec **Commit changes**.
3. Allez dans **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
5. Après une à deux minutes, le guide est en ligne à l'adresse :
   `https://VOTRE-NOM.github.io/guide-korg-sv1/`

Pour modifier le guide plus tard : ouvrez `index.html` sur GitHub, cliquez sur le crayon ✏️, modifiez, puis **Commit changes**. La page se met à jour automatiquement.
